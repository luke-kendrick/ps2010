8 Factorial ANOVA (Mixed Design & Covariate)

Learning Outcomes

By the end of this chapter you should be able to:

The data for this chapter come from:

Winter, M., Will, A.J., Ingersoll, J., Meyer, M.J., & Clabough, E.B.D (2026). Keep the Bedtime Story: A Daily Reading Ritual Improves Empathy and Creativity in Children. Affective Science, 3(3), 519–527, doi:10.1007/s42761-022-00126-5.

In this study, the researchers investigated if a short daily bedtime reading routine could influence children’s empathy and creativity. This chapter will focus on the measure of creativity.

Children took part in one of two reading conditions (called Treatment in the data file): a pause condition where the reading routine included pauses in which children were asked two reflective questions, or a read-through condition which did not include pauses or reflective questions. Children completed measures of empathy and creativity before and after the intervention (see occasion in the data file). In this chapter you will analyse the measure of creativity, specifically fluency in divergent thinking (measured using Wallach-Kogan Alternative Uses Test).

The primary research question is whether the change in fluency from the initial assessment to follow-up differs between the two reading conditions.

8.2.2 Pivot Data

As one of the variables are repeated measures, you will need to check if the data in its current form is in long format.

❓ Help

Spoiler alert It is not in long format. This is because there is not a single column that contains the dependent variable. This is because InitialFluency and FollowFluency are in separate columns, meaning these data are in wide format.

data <- pivot_longer(cols =c(InitialFluency, FollowFluency),
    names_to = "occasion",
    values_to = "fluency")
🔍 Code Explained

pivot_longer() changes the data from wide format to long format. It takes the two fluency columns and places their names in a new occasion column and their scores in a new fluency column.

  • data <- saves the result in an object called data.
  • dat %>% supplies the existing dataset to pivot_longer().
  • cols = c(...) the columns you should reshape.
  • names_to = "occasion" creates a column for the independent variable.
  • values_to = "fluency" creates a column containing the scores (dependent variable).

8.2.3 Factorise and Rename Variables

The Treatment and occasion variables are both factors, and so they need to be changed as “Factor”.

data <- data %>% 
  mutate(Treatment = factor(Treatment, labels = c("readthrough", "pause")),
        occasion = factor(occasion, levels = c("InitialFluency", "FollowFluency")))

The mixing of uppercase and lowercase for the factor names is annoying. Stick with best practice and keep everything lowercase.

names(data) <- tolower(names(data))

8.5 Check Assumptions

8.5.1 Continuous Dependent Variable

The dependent variable should be numerical and a continuous score.

This assumption holds for this study.

8.5.2 Independent Observations

Each child should only be in only one treatment condition.

Although each child’s score is related (repeated measures), each child’s set of observations are independent from one another. In other words, each child’s scores should not influence another child’s scores.

8.5.3 Roughly Normally Distributed Residuals

The residuals from the ANOVA model should be approximately normally distributed.

You can use the same approach as previously.

res <- residuals(mod$lm)

Homogeneity of Variance

For more complex designs you might consider using check_homogeneity() from the performance package. This will use Levene’s Test check homogeneity of variance across all groups.

install.packages("performance")
library(performance)

check_homogeneity(mod, method = "levene")

You can also visualise the variances:

plot(check_homogeneity(mod, method = "levene"))
❓ Help

For some unknown reason, the performance package has been a bit temperamental on Campus PCs in the past.

If the above does not work, use the old fashioned approach (note: you need to run a Levene’s Test at each level of the within subjects variable, so one for InitialFluency and then one for FollowFluency)

#First for initialfluency
leveneTest(fluency ~ treatment,
           data = filter(data, occasion == "InitialFluency"))

#Then for followfluency
leveneTest(fluency ~ treatment,
           data = filter(data, occasion == "FollowFluency"))
