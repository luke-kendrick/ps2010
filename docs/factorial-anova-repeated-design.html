9 Factorial ANOVA (Repeated Design)

Learning Outcomes

By the end of this chapter you should be able to:

  • Wrangle and pivot a data set in preparation for a 3 × 2 repeated factorial ANOVA.
  • Produce descriptive statistics and visualisations for a factorial design.
  • Check the assumptions of a factorial ANOVA.
  • Understand how to check the assumption of Sphericity and select a suitable model correction if needed.
  • Conduct and interpret a 3 × 2 repeated factorial ANOVA in R.
  • Interpret main effects and interactions between two independent variables.
  • Conduct and interpret simple-effects analyses following a significant interaction.
  • Report the results of a factorial ANOVA and simple-effects analyses in APA style.

The data for this chapter come from:

El Basbasse, Y., Packheiser, J., Peterburs, J., Maymon, C., Güntürkün, O., Grimshaw, G., & Ocklenburg, S. (2023). Walk the plank! Using mobile electroencephalography to investigate emotional lateralization of immersive fear in virtual reality. Royal Society Open Science, 10(5), 221239. doi:10.1098/rsos.221239

In this study, the researchers investigated experiencing a virtual reality (VR) “walk the plank” would induce fear, and whether fear increased as participants moved along the plank. Participants completed two different plank conditions: a neutral condition where the plank was at street level and a negative condition where the plank was positioned at the top of a high rise building.

Participants completed a subjective fear rating scale (higher score indicates greater fear) at three time points during the VR task: (1) in the elevator before the plank, (2) at the start of the plank, and (3) at the end of the plank.

This study includes other measures, including physiological (e.g., EEG) and other behavioural tasks, however, for this chapter you will analyse the subjective fear rating data. Your task is the replicate the analysis presented in section 3.2.1 of the published paper.

9.2 Data Wrangling

9.2.1 Select Variables

You will not need to include all variables in the data set. Use the select() function to include: the participant identifier variable, and then the repeated conditions:negative_elevator, negative_start, negative_end, neutral_elevator neutral_start, and neutral_end.

Save these as a new object called data.

❓ Help 
data <- dat %>%
  select(NULL, NULL, NULL, NULL)

9.2.2 Pivot Data

As some of the variables are repeated measures, you will need to check if the data in its current form is in long format and pivot if needed.

datalong <- data %>%
  pivot_longer(
    cols = -subject,
    names_to = c("cond", "time"),
    names_pattern = "(neutral|negative)_(.*)",
    values_to = "fear")
🔍 Code Explained

The data are reshaped from wide to long format so that the fear ratings for the different conditions and recording points are stored in separate columns.

  • datalong <- plank %>% starts with the wide-format data frame plank and saves the reshaped data as datalong.
  • pivot_longer() converts several columns into rows.
  • cols = -subject pivots every column except subject. The subject identifier is kept on each row so the observations can still be linked to each participant.
  • names_to = c("cond", "time") splits the original column names into two new variables: cond for the condition and time for the recording point.
  • names_pattern = "(neutral|negative)_(.*)" tells R how to split each column name. The first set of brackets captures either neutral or negative; the second captures the text after the underscore, such as elevator or start_of_plank.
  • values_to = "fear" puts the ratings from the original columns into a new variable called fear.

The resulting data have one row for each participant, condition and recording point.

9.2.3 Factorise and Rename Variables

The cond and time variables are both factors, and so they need to be coded as a “Factor”.

datalong <- datalong %>% 
  mutate(cond = factor(cond, levels = c("neutral", "negative")),
         time = factor(time, levels = c("elevator", "start", "end")))

The variable names are clear enough, and so no renaming needed.

levels = c() is useful here because we need to put the levels of time in a logical order rather than R’s default alphabetical. Remember that elevator comes first, then start, then end at the end of this experiment.

9.5 Check Assumptions

9.5.1 Continuous Dependent Variable

The dependent variable should be numerical and a continuous score.

This assumption holds for this study.

9.5.2 Independent Observations

This is a fully repeated-measures design: each participant provided fear ratings in both conditions (neutral and negative) and at all three recording locations. Their scores across these conditions and locations are therefore related.

The independence assumption applies between participants: one participant’s ratings should not influence another participant’s ratings. This is assumed from the study design.

9.5.3 Roughly Normally Distributed Residuals

The residuals from the ANOVA model should be approximately normally distributed.

You can use the same approach as previously.

Obtaining the Model Residuals

If you need a reminder of the variable names use:

names(datalong)

Then fit the model:

mod <- aov_ez(id = "NULL",
       data = NULL, 
       within = c("NULL", "NULL"),
       dv = "NULL", 
       type = 3,
       anova_table = list(es = "pes"))

Q-Q Plot and Shapiro-Wilk

This is not new to you by now. Use the code below and interpret the output.

res <- residuals(mod$lm)
qqPlot(res)
shapiro.test(res)

Sphericity

To check for sphericity, we again need to use the model mod from earlier. This time use:

summary(mod)

Check the output for “Mauchly Tests for Sphericity” and interpret the test(s).

Reporting this is the same as the Shapiro-Wilk test, you just need to report the test statistics (w = XX) and the p-value.

Issues with Assumptions

9.6 Summary of Assumption Checks

The Shapiro–Wilk test was significant (W = 0.951, p < .001), and the Q–Q plot shows that the residuals do not follow a normal distribution closely, particularly at the tails.

Mauchly’s test was also significant, indicating that the assumption of sphericity was violated. This affects the location factor and the cond × location interaction, because location has three levels. Sphericity is automatically met for cond, which has two levels.

For the effects involving location, we use the Greenhouse–Geisser corrected results. This correction accounts for the sphericity violation, but it does not address the non-normality of the residuals. The assumptions are therefore not fully met, so the results should be interpreted with caution. This does not automatically mean that the analysis cannot be used; real data are messy. Real data do not always meet every assumption.

9.7 Interpret the ANOVA

You already did the hard work earlier setting up the code for the ANOVA model. Now you will just need to call it back.

If the sphericity assumption was not met, use this to check the corrected model output. You’ll know the correction has been applied as the degrees of freedom are not whole number (they have decimal places).

nice(mod, es = "pes", correction = "GG")

If the sphericity assumption has been met, then use this to check the uncorrected model output:

nice(mod, es = "pes", correction = "none")

The two options above will allow you to use either the uncorrected model (if Sphericity was met) or the corrected model (if the assumption of Sphericity was not met).

9.8 Simple Effects Analysis

The interaction asks whether the difference in fear ratings between the neutral and negative conditions changes across the three locations. To explore this, we will compare the two conditions at each location: elevator, start and end.

First, plot the data.

afex_plot(object = mod, 
          x = "time", 
          trace = "cond", 
          error = "within") +
  theme_classic()

You used this code last week but see below for a reminder of how it works.

🔍 Code Explained
  • x = sets the x-axis variable. Here, location has three levels: elevator, start and end.
  • trace = separates the data by another variable. Here, cond shows the neutral and negative conditions at each location.
  • error = "within" is used because both location and cond are within-subjects variables. Each participant provided ratings in every condition and at every location.

Now obtain the statistics for the pairwise comparisons so you can interpret them alongside the afex_plot().

emmeans(mod, ~ cond*time) %>% 
  contrast(interaction = "pairwise", 
           simple = "each", 
           combine = FALSE, 
           adjust = "bonferroni")

Look through the output and select the relevant comparisons. For this simple effects analysis, report the t-tests comparing the neutral and negative conditions at each location: elevator, start and end.

In total, you will need three t-tests per cond (three for neutral, three for negative). The Bonferroni adjustment (used in the published paper) is applied to account for multiple comparisons.

Remember to include effect sizes…

datalong %>%
    group_by(cond) %>%
      rstatix::cohens_d(
        fear ~ time,
        paired = TRUE)
