5 One-Way ANOVA (Repeated)

Learning Outcomes

By the end of this chapter you should be able to:

  • produce descriptive statistics and plots appropriate for a one-way ANOVA
  • check the relevant assumptions for a one-way ANOVA (repeated design), including Sphericity
  • run and interpret the ANOVA using aov_ez(), using emmeans() and polynomial contrasts
  • write up the results in a style suitable for a lab report.

5.1 Before You Begin

The data for this chapter come from:

Wadsley, M., & Ihssen, N. (2023). Restricting social networking site use for one week produces varied effects on mood but does not increase explicit or implicit desires to use SNSs: Findings from an ecological momentary assessment study. PLoS one, 18(11), e0293467. doi: 10.1371/journal.pone.0293467

You’ll only be using a couple of the variables from this study. However, you should read the full paper so that you have an understanding of the study aim(s) and methodology but the key information for today’s analysis is below.

In this study the researchers were interested in exploring the effects of restricting social networking site (e.g., Facebook, Instagram) use for one week. They included a range of different psychological measures and today you’ll be looking at two of the dependent variables:

  1. Social network site (SNS) screen time. Time spent (in minutes) on social network sites. This is to check that participants did indeed reduce their social network site use during the intervention.
  2. Positive affect. Previous research suggests that positive affect (mood) can decrease when people stop using social media (e.g., a type of withdrawal effect). This was measured using a 0-100 scale (high score indicating greater positive mood).

Participants completed these measures at three time points (making this a repeated measures design): baseline, intervention, post-intervention. During the intervention stage, participants were instructed to abstain from using all SNSs (e.g., no using Instagram, Facebook, Twitter; but they could use instant messaging or voice/video calling apps e.g., WhatsApp or Messenger) for the next 7 days

Today you will analyse the data slightly differently to the original paper. We will check:

  • Research Question 1: Did the intervention actually reduce SNS screen time? In other words, did participants do what they were instructed! We’d expect a quadratic trend as usage should initially decrease for the intervention stage but then possibly increase after.

  • Reduce Question 2: Does positive mood reduce as a result of SNS abstinence? As previous research has hinted that positive mood scores do decline when abstaining from social media, we will also be using a polynomial planned contrast to look at a possible quadratic or linear trend here too.

5.4 Research Question 1: Screen Time

Before we start, the data are not in long format which for repeated measures we will need.

Convert the data to long format using the pivot_longer() function:

longd <- screentime %>%
  pivot_longer(
    cols = t1:t3,
    names_to = "time",
    values_to = "mins")
    
view(longd)
🔍 Code Explained

  • longd <- screentime %>% will take the screen time data set and pass it to the next function (after %>%). Anything after this will be saved as a new object called longd (shorthand name for long data).

  • pivot_longer() is the function used to convert the data from wide to long format. It has three arguments.

  • cols = t1:t3 will select the columns from t1 through to t3 (by using :). This is a quick way to select multiple columns.

  • names_to = "time" will create a new column where we will place our original columns (t1, t2, t3) and gives it a name time (shorthand for time point).

  • values_to = "mins" places our actual data (the screen time in minutes) into a column and give it a name mins (shorthand for minutes)

You should also check the levels and re-order if necessary

#use this to change the levels
longd$time <- factor(longd$time, levels = c("NULL", "NULL", "NULL"))

5.7 Check Assumptions

There are four main assumptions for a one-way ANOVA (repeated design) that we will consider here.

5.7.1 Continuous Dependent Variable

The dependent variable should be numerical and a continuous score.

Time in mins is continuous.

5.7.2 Independent Observations

Although this is a repeated measures design and participants’ observations are related, each participant’s set of observations are independent from one another. This assumption holds for this study.

5.7.3 Roughly Normally Distributed Model Residuals

This week we will use a slightly different method to check normality. This time we will check the model residuals. This is a quicker approach for an ANOVA with a repeated measures variable.

Obtaining the Model Residuals

In order to do this though, we need to actually run the ANOVA model first and store it as an object (called mod). The code is very similar to last week, and check your lecture notes if you need help understanding it.

mod <- aov_ez(id = "id",
              data = long,
              dv = "min",
              within = "time",
              type = 3,
              anova_table = list(es = "pes"))

Oh! By the way, there are a few typos in the code above which you will need to fix before saving this model. Sorry, I’m not going to make it that easy for you!

Once you have fixed my errors, you should see mod appear in the environment (top right) panel.

We need to pull out the residuals information from the model and save them to an object called res.

res <- residuals(mod$lm)

5.7.4 Q-Q Plot

You can use a Q-Q plot to check the model residuals saved as res. This week we will use the qqPlot function from the car package.

qqPlot(res)

Hmmm! That Q-Q plot looks somewhat “snakey” 🐍. Let’s try the Shapiro-Wilk test to see if this tells us the same thing.

5.7.4.1 Shapiro-Wilk Test 

shapiro.test(res)

Now we have both the Q-Q plot and the Shapiro-Wilk test telling us we may have an issue with this assumption.

🔍 Learn More

Why is the distribution skewed?

It is likely due to time. No, not the passing of time, but the dependent variable screen time (in minutes). Time and reaction time data are quite often skewed, and is perhaps more unusual if it is normally distributed.

This means it is no surprise the QQ plot and S-W test suggest there is a departure from approximate normality.

If you have read the paper you may have noticed that the researchers do just go ahead and report the ANOVA and there is no mention of normality anywhere…

ANOVAs are generally fairly robust against small to moderate non-normality, providing there is a balanced design (e.g., equal sample sizes or that all participants in a repeated measures design had scores for every condition). This study has a reasonable sample size of 51 and it was true that each participant had scores for each time point.

Another option could be to run a non-parametric alternative. More on this later on in term, for now we will continue.

5.7.5 Sphericity

To check for sphericity, we again need to use the model mod from earlier. This time use:

summary(mod)

Check the output for “Mauchly Tests for Sphericity” and interpret the test(s).

Reporting this is the same as the Shapiro-Wilk test, you just need to report the test statistics (w = XX) and the p-value. Here is an example of what it could look like:

W = 0.90, p = .074

5.8 Interpret the ANOVA

You already did the hard work earlier setting up the code for the ANOVA model. Now you will just need to call it back.

If the sphericity assumption was not met, use this to check the corrected model output. You’ll know the correction has been applied as the degrees of freedom are not whole number (they have decimal places).

nice(mod, es = "pes", correction = "GG")

If the sphericity assumption has been met, then use this to check the uncorrected model output:

nice(mod, es = "pes", correction = "none")

The two options above will allow you to use either the uncorrected model (if Sphericity was met) or the corrected model (if the assumption of Sphericity was not met).

5.9 Run and Interpret the Planned Contrast

The researchers in the published paper used post-hoc comparisons, although they do not actually specify if an alpha level correction (e.g., Holm, Bonferroni, Tukey) was used.

As the focus this week is to look at planned contrasts, it would be reasonable to expect a quadratic relationship between time point and screen time minutes. In other words, we’d expect a decrease from t1 to t2 but then an increase from t2 to t3. This would essentially form a “U-shaped” pattern.

#as with post-hocs (last week), pull out the emmeans
emms <- emmeans(mod, ~ time)
poly <- contrast(emms, method = "poly")

print(poly) # print the results to the console

You can also use the code below to visualise the quadratic using a simple line graph.

ggplot(longd, aes(x = time, y = mins, group = 1)) +
  stat_summary(fun = mean, geom = "line") +
  theme_classic()

5.13.2 Independent Observations
