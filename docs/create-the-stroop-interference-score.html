7 Create the Stroop Interference Score

Remember our research question: Does distracting background noise affect Stroop interference?

We need to calculate the interference score for every participant by subtracting their congruent mean RT from their incongruent mean RT.

This is a good opportunity to use mutate(), which creates new variables:

wide_data <- wide_data %>%
  mutate(stroop_effect = incongruent - congruent)

View(wide_data)
🔍 Code Explained

mutate() adds a new variable called stroop_effect. For example, if someone has a mean congruent RT of 550 ms and a mean incongruent RT of 700 ms, their interference score would be 150 ms.

A larger positive score means more interference. A score near zero means there is little difference between the two conditions. A negative score means the participant was faster on incongruent trials.

7.1 Create the Final Dataset

We only need three variables for the final two-sample t-test: participant ID, experimental group, and interference score.

Use select(),rename(), and mutate() to make your dataset a little tidier:

int <- wide_data %>%
  select(id, GROUP, stroop_effect) %>%
  rename(int = stroop_effect, group = GROUP) %>%
  mutate(GROUP = factor(GROUP, levels = c("quiet", "distractor")))

View(int)
🔍 Code Explained
  • select() keeps only the three variables needed.
  • rename() changes stroop_effect to the shorter name int (interference). Change GROUP to group as I prefer lowercase variable names.
  • factor() sets the order of the two groups, this can be helpful if you conditions need to be in a particular order rather than just alphabetically.

We no longer need a COND column: the two congruency means have already been combined into one interference score for each participant.
