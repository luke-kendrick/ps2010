1 Descriptive Statistics and Plots

Learning Outcomes

By the end of this chapter you should be able to:

  • import and view data using read_csv() and view()
  • select relevant variables using select()
  • calculate descriptive statistics, including the mean and standard deviation.
  • create and interpret a histogram and a density plot
  • create and interpret a box plot and a violin plot

1.1 Setup

The data for this workshop come from:

Gamble, T., & Walker, I. (2016). Wearing a Bicycle Helmet Can Increase Risk Taking and Sensation Seeking in Adults. Psychological Science, 27(2), 289–294, doi: 10.1177/09567976156207

In this study, the researchers wanted to compare risk taking behaviour between a group wearing a bicycle helmet and one wearing a baseball cap. Participants were randomly assigned to one of these groups and completed the Balloon Analogue Risk Task (BART), which, which measured their risk taking behaviour.

In this chapter you will use the real data from the published paper to look at the descriptive statistics in their results section in addition to exploring the data with different plots.

Q1(a) What would be a suitable research question for this study?

1.2 Load Packages and Import Data

1.2.1 Load Package(s)

You only need one package today:

library(tidyverse) # loads tidyverse package
❓ Help

If you see this error: there is no package called ‘tidyverse’ Make sure the Tidyverse package is installed before you load it.

install.packages("tidyverse")

1.2.2 Import Data

Remember to set your working directory first!

Use this code:

data <- read_csv("risky.csv")
🔍 Code Explained

This code will create an object called ‘data’

The assignment operator arrow <- means anything to the right side will be passed into the object.

read_csv(risky.csv) will then look in your working directory to find a file called “risky.csv”.

1.3 View and Filter the Data

Once you have imported data take a look at it using the view() function.

view(data)

For this chapter we are only interested in these variables:

  • condition: this tells us if participants were in the helmet or baseball cap condition.

  • BART: this was the dependent variable and tells us how risky participants were. A higher score indicates greater risk taking.

  • id: it is always helpful to use an identification variable for each participant, whilst strictly not an experimental variable, you should keep it.

Q2a: Which participant ID had the highest risk taking (BART) score?

Tip: You can sort a column when viewing data by clicking on the variable name.

Q2b: What was the risk taking (BART) score for participant ID 63?

1.4 Descriptive Statistics

Calculate the mean and standard deviation for the BART score for both the helmet and beseball cap groups:

stats <- data %>%
  group_by(condition) %>%
  summarise(meanBART = mean(BART),
            sdBART = sd(BART)

1.5 Histogram

For the remaining part of this chapter, you should focus on exploring and interpreting the plots.

Try not to worry too much about the specifics of the code right now.

This is because you will learn about ggplot2 code (data visualisation) later on in term. For now just focus on adding the variable names and producing the basic plots.

Create a histogram, but change the word NULL1 to what you want to show on the x-axis (tip: it should be the name of dependent variable) and NULL2 to your independent variable:

ggplot(data, aes(x = NULL1, fill =NUll2)) +
  geom_histogram(bins = 20, colour = "black")

1.5.1 Create Separate Histograms

You can use the facet_wrap() function to separate the histograms by condition:

ggplot(data, aes(x = NULL1, fill =NUll2)) +
  geom_histogram(bins = 20, colour = "black") +
  facet_wrap(~ condition)

1.6 Density Plot

Create a density plot, again you will need to change NULL1 and NULL2 to the dependent variable:

ggplot(data, aes(x = NULL1, fill = NULL2)) +
  geom_density(alpha = 0.2)

Q4a When looking at the density plot, which condition (cap or helmet) had greater density of higher risk taking scores?

Q4b When looking at the density plot, which condition (cap or helmet) had greater density of lower risk taking scores?

1.7 Box Plot

Create a box plot (note the change of the x and y axis for this one)…

ggplot(data, aes(x = NULL2, y = NULL1)) +
  geom_boxplot()

Look back at your mean and standard deviations from questions 1(a) and 1(b). Do they match what the box plots show?

1.8 Violin Plot

Create a box plot…

ggplot(data, aes(x = NULL2, y = NULL1)) +
  geom_violin(alpha = 0) +
  geom_boxplot(width = 0.2)

1.9 Optional Exercise

You can tidy up your plots a little bit by adding an extra line of code…

Try adding + and then theme_classic() to the end of your plots.

For example:

ggplot(data, aes(x = condition, y = BART)) +
  geom_violin(alpha = 0) +
  geom_boxplot(width = 0.2) +
  theme_classic()
