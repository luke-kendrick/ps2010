7 Factorial ANOVA (Independent Design)

Learning Outcomes

By the end of this chapter you should be able to:

  • Prepare and organise data for a 2 × 2 independent measures factorial ANOVA.
  • Produce descriptive statistics and visualisations for a factorial design.
  • Check the assumptions of a factorial ANOVA.
  • Conduct and interpret a 2 × 2 independent measures factorial ANOVA in R.
  • Interpret main effects and interactions between two independent variables.
  • Conduct and interpret simple-effects analyses following a significant interaction.
  • Report the results of a factorial ANOVA and simple-effects analyses in APA style.

7.1 Before You Begin

The data for this chapter come from:

Gunderson, C. A., Vo, T. V. A., Harriot, B., Kam, C., & ten Brinke, L. (2022). In search of duping delight. Affective Science, 3(3), 519–527, doi:10.1007/s42761-022-00126-5.

In this study, the researchers investigated whether lying and receiving feedback that you are believed leads to “duper’s delight”, a positive emotional response to successfully deceiving someone.

Participants (N = 167) were asked to imagine that items had been stolen from their office. They were randomly assigned to either tell the truth about which items were stolen or lie by claiming additional items had been taken. They then completed a video-recorded interview about the theft and received feedback from a supposed computer algorithm indicating whether their account was believable or not believable. In reality, this feedback was randomly assigned. Afterwards, participants completed a questionnaire measuring their positive and negative emotions.

The researchers aimed to investigate whether the effect of receiving believable or not believable feedback on emotions depended on whether participants had lied or told the truth.

7.3 Prepare Data

You will notice there are quite a few variables in this original data set. Use the code below to prepare it for analysis:

data <- dat %>%
  select(Veracity, Feedback, Positive.Affect, Negative.Affect) %>%
  mutate(id = row_number(), .before = 1)

You have used the code above before, so you should be able to make sense of what it is doing. The mutate() bit of code will ensure an id column is added, as you’ll need that for the analysis later.

You might notice the variable names use a mix of upper and lower case letters. I hate this. The code below will change them all to lowercase

names(data) <- tolower(names(data))

If you view the data file, you will notice the veracity and feedback conditions are coded as 0 or 1. Let’s change these to more informative values.

For the feedback condition: > 0 = Notbelievable, 1 Believable.

For Veracity (whether someone lied or not): > 0 = Lie, 1 = Truth.

Change them with the code below:

data <- data %>%
  mutate(feedback = factor(feedback,
                           levels = c(0, 1),
                           labels = c("notbelievable", "believable")),
         veracity = factor(veracity,
                           levels = c(0, 1),
                           labels = c("lie", "truth")))

Now if you check the data file you should see that the zeros and ones have been replaced with the labels.

The final step here is to export and save the current data set as a .csv file format that you are more familiar with.

write.csv(data, "lies.csv", row.names = FALSE)

This code will take the object called data and save it as a file called lies.csv and automatically save it in your working directory.

After this, you should re-load the new .csv file and work with it for the rest of this chapter.

data <- read_csv("lies.csv")

For those of you who read the paper before today (hopefully all of you!), you may have noticed that the researchers found a significant interaction for negative affect, but not positive affect. For the next section, we will therefore focus on negative.affect as our dependent variable.

7.6 Check Assumptions

7.6.1 Continuous Dependent Variable

The dependent variable should be numerical and a continuous score.

This assumption holds for this study.

7.6.2 Independent Observations

Each participant was assigned to one of the four conditions and provided one set of observations. Therefore, we assume that observations are independent.

7.6.3 Roughly Normally Distributed Residuals

The residuals from the ANOVA model should be approximately normally distributed.

You can use the same approach as previously.

Obtaining the Model Residuals 

mod <- aov_ez(id = "NULL",
       data = NULL, 
       between = c("NULL", "NULL"), 
       dv = "NULL", 
       type = 3,
       anova_table = list(es = "pes"))

The following information will need adding: veracity, feedback, id, data, negative.affect.

Q-Q Plot and Shapiro-Wilk

This is not new to you by now. Use the code below and interpret the output.

res <- residuals(mod$lm)
qqPlot(res)
shapiro.test(res)

Homogeneity of Variance

You will need to check whether the variances/spread of data points look fairly similar (or homogeneous) across the combination of conditions.

Levene’s test will check this assumption. Note: it uses a formulaic argument, see below for DV ~ IV.

leveneTest(negative.affect ~ veracity*feedback, data)

The * allows Levene’s test to compare variances across all four combinations (e.g., in a factorial design) of veracity and feedback conditions.

7.8 Simple Effects Analysis

As there is a significant interaction, you should plot it.

afex_plot(object = mod, 
          x = "veracity", 
          trace = "feedback",
          legend_title = "Feedback",
          error = "between",
          factor_levels = list(veracity = c("lie", "truth"))) + 
  theme_classic()

Next, pull out the emmeans and run contrasts using a “holm” correction. Your results may differ slightly from those reported in the paper because we are using emmeans() to conduct simple-effects comparisons, whereas the researchers used separate independent-samples t-tests. Both approaches examine the same group differences but use different estimates of variability.

Also, because you’re applying Holm corrections, the adjusted p values may differ for that reason too.

emmeans(mod, ~ feedback | veracity) %>%
  pairs(adjust = "none") %>%
  test(by = NULL, adjust = "holm")

Don’t forget the effect size:

data %>%
  group_by(veracity) %>%
  rstatix::cohens_d(negative.affect ~ feedback,
                   paired = FALSE)
